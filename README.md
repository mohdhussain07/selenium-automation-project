# Selenium Automation Testing Project

## Project Overview
This project is a beginner-friendly Selenium Automation Testing framework developed using Java and Selenium WebDriver.  
The project automates testing scenarios for the SauceDemo website.

Website Tested:  
https://www.saucedemo.com/

The purpose of this project is to demonstrate basic automation testing skills including:
- Login Validation
- Invalid Login Handling
- Logout Functionality Testing

---

# Tech Stack

- Java
- Selenium WebDriver
- Maven
- IntelliJ IDEA
- Chrome Browser

---

# Test Scenarios Covered

- Enters valid username and password
